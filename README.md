# ServiceHub - Платформа для размещения и выполнения услуг

Комплексное веб-приложение для поиска исполнителей и размещения услуг.

## 🚀 Функционал

### Для заказчиков
- 🔍 Поиск услуг по категориям, цене, рейтингу
- 📋 Просмотр детальной информации об услугах
- 💬 Прямая связь с исполнителями
- ⭐ Система отзывов и рейтингов
- 🔐 Безопасные сделки через escrow-систему
- 📊 Отслеживание статуса заказов

### Для исполнителей
- 📝 Создание и управление услугами
- 📈 Панель управления с аналитикой
- 💰 Отслеживание заработка
- 📬 Управление заказами
- ⭐ Накопление рейтинга и отзывов

### Авторизация
- 🔑 Регистрация с выбором роли (заказчик/исполнитель)
- 🔐 Вход с хешированием паролей (bcrypt)
- 🔄 Восстановление пароля
- 👤 Управление профилем
- ⚙️ Настройки уведомлений

## 🛠 Технологии

- **React 18** - UI библиотека
- **TypeScript** - Типизация
- **React Router v6** - Маршрутизация
- **Tailwind CSS** - Стилизация
- **bcryptjs** - Хеширование паролей
- **Vite** - Сборка проекта

```
src/
├── context/
│   ├── AuthContext.tsx      # Контекст авторизации
│   └── ServicesContext.tsx  # Контекст услуг и заказов
├── components/
│   ├── layout/
│   │   ├── Header.tsx       # Шапка сайта
│   │   └── Footer.tsx       # Подвал сайта
│   └── ProtectedRoute.tsx   # Защищённые маршруты
├── pages/
│   ├── auth/
│   │   ├── Login.tsx        # Вход
│   │   ├── Register.tsx     # Регистрация
│   │   └── ForgotPassword.tsx # Восстановление пароля
│   ├── Home.tsx             # Главная страница
│   ├── Services.tsx         # Каталог услуг
│   ├── ServiceDetail.tsx    # Детали услуги
│   ├── Categories.tsx       # Категории
│   ├── CreateService.tsx    # Создание услуги
│   ├── Profile.tsx          # Профиль пользователя
│   ├── Orders.tsx           # Заказы
│   ├── Messages.tsx         # Сообщения
│   ├── Dashboard.tsx        # Панель исполнителя
│   └── Settings.tsx         # Настройки

├── main.tsx                 # Точка входа
```

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## 📊 Хранение данных

Данные хранятся в localStorage браузера:
- `service_platform_auth` - Сессия пользователя
- `service_platform_users` - Пользователи
- `service_platform_services` - Услуги
- `service_platform_orders` - Заказы
- `service_platform_messages` - Сообщения
- `service_platform_reviews` - Отзывы

## 🎨 Дизайн

- Тёмная тема с градиентами purple/pink
- Стеклянный эффект (glassmorphism)
- Адаптивный дизайн для всех устройств
- Плавные анимации и переходы

## 🔐 Безопасность

- Хеширование паролей с bcrypt (salt rounds: 10)
- Сессионная авторизация с expiration
- Защищённые маршруты для авторизованных пользователей
- Валидация форм на клиенте

## 📱 Страницы

### Публичные
- `/` - Главная страница
- `/services` - Каталог услуг
- `/service/:id` - Детали услуги
- `/categories` - Все категории
- `/login` - Вход
- `/register` - Регистрация
- `/forgot-password` - Восстановление пароля

### Защищённые
- `/profile` - Профиль пользователя
- `/orders` - Заказы
- `/messages` - Сообщения
- `/messages/:orderId` - Чат заказа
- `/settings` - Настройки
- `/create-service` - Создание услуги (только исполнители)
- `/dashboard` - Панель исполнителя (только исполнители)

## 🧪 Тестовые данные

При первом запуске создаются демонстрационные услуги в категориях:
- Дизайн
- Разработка
- Маркетинг
- Тексты
- Видео
- Аудио
